# segment

将一个数值随机分成若干段，每段长度在指定范围内。

```ts
import { segment } from '@fexd/tools'
```

## 适用场景

- 动画效果中将总时长随机分配到各阶段
- 游戏开发中将资源/区域随机划分
- 数据可视化中随机分配数据段权重
- A/B 测试中将流量随机分组

## 不适用场景

- 需要均匀分段时（应直接用除法）
- 需要确定性结果（每次调用结果不同）
- 总量无法被约束条件满足时会抛错，不适合不可控输入

## 签名

```ts
function segment(length: number, count: number, [min, max]: number[]): number[]
```

## 用法

```ts
segment(100, 5, [10, 30])
// => [22, 15, 28, 18, 17]（每次结果不同，各段之和 = 100）

segment(50, 3, [10, 20])
// => [16, 14, 20]
```

## 注意事项

- 若 `length / count` 超出 `[min, max]` 范围，会抛出错误 `'无法分段'`
- 结果为浮点数

## 相关函数

- `random` — segment 内部依赖 random 生成分段随机值
- `clamp` — 可对分段结果做范围约束
