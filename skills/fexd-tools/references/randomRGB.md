# randomRGB

随机生成一个 Hex 格式的 RGB 颜色值。

```ts
import { randomRGB } from '@fexd/tools'
```

## 适用场景

- 生成随机占位颜色（头像、标签、图表色块等）
- 需要确保生成颜色不过暗时配合 min 参数使用
- 快速原型或演示中填充视觉元素

## 不适用场景

- 需要可复现的确定颜色（函数随机生成，不保证唯一或可控）
- 需要生成 HSL 或指定色相范围的颜色
- 需要色盲友好的调色板生成

## 签名

```ts
const randomRGB = (min?: number): string
```

## 参数

| 参数  | 类型     | 默认值 | 说明                                |
| ----- | -------- | ------ | ----------------------------------- |
| `min` | `number` | `0`    | 每个通道的最小值（0–255），避免过暗 |

## 用法

```ts
randomRGB() // => '#a3f2c1'（随机）
randomRGB(128) // => '#e4d8f0'（较亮的颜色）
```

## 注意事项

- 每个通道值范围为 `[min, 255)`
- `min = 128` 可确保生成较亮的颜色

## 相关函数

- `hexToRgb` — 将生成的 Hex 颜色解析为 RGB 对象
- `darkenColor` — 加深随机生成的颜色
- `random` — 底层随机数生成工具
