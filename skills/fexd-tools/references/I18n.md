# I18n

国际化工具类，支持多语言翻译、资源加载、格式化模板、命名空间、类型系统。

```ts
import { I18n } from '@fexd/tools'
```

## 适用场景

- 前端应用多语言翻译
- 多层级语言包注册（基础层、业务层、应用层），需要优先级控制
- 需要格式化模板（如 `hello {{name}}`）
- 命名空间隔离不同模块的翻译资源
- 动态异步加载语言资源

## 不适用场景

- 仅需简单字符串模板，无需多语言 → 用 `I18n.template`
- 服务端渲染需要实例隔离 → I18n 是单例模式，全局切换语言
- 需要复杂的 ICU MessageFormat → 内置模板仅支持 `{{key}}` 插值

## 基本用法

```ts
const i18n = new I18n({
  types: {
    default: {
      resources: {
        'zh-CN': { hello: '你好', 'greeting.morning': '早上好' },
        'en-US': { hello: 'Hello', 'greeting.morning': 'Good morning' },
      },
    },
  },
  defaultType: 'default',
  splitByDot: 'auto',
})

await I18n.applyLanguage('zh-CN')

i18n.t('hello') // '你好'
i18n.t('greeting.morning') // '早上好'（splitByDot='auto' 优先按点分割）
i18n.t('hello', { '@type': 'default' }) // 指定类型
i18n.t('common:shared', { '@namespace': 'common' }) // 指定命名空间
```

## 静态方法

| 方法                                | 说明                                                                               |
| ----------------------------------- | ---------------------------------------------------------------------------------- |
| `I18n.applyLanguage(lang)`          | 全局切换语言，更新所有实例                                                         |
| `I18n.applyLng(lang)`               | `applyLanguage` 的别名                                                             |
| `I18n.template(str, data, options)` | 简易字符串模板：`I18n.template('hello {{name}}', { name: 'CJY' })` → `'hello CJY'` |
| `I18n.load(...loaders)`             | 创建异步资源加载器                                                                 |

## 实例配置

```ts
interface I18nConfig {
  types?: Record<
    string,
    {
      resources?: Record<any, any> | false
      format?: any
    }
  >
  splitByDot?: boolean | 'auto'
  defaultType?: string
  fallback?: I18n[] | Record<any, any>
  translateFallback?: ((keys: any, options: any) => any) | any
  defaultApplyMode?: 'override' | 'supplement'
}
```

## 翻译语法

| 语法             | 示例                                       | 说明             |
| ---------------- | ------------------------------------------ | ---------------- |
| 简单 key         | `t('hello')`                               | 直接翻译         |
| @type            | `t('key@error')`                           | 指定类型         |
| namespace:key    | `t('common:shared')`                       | 命名空间         |
| @namespace 选项  | `t('shared', { '@namespace': 'common' })`  | 选项指定命名空间 |
| @splitByDot 选项 | `t('user.name', { '@splitByDot': false })` | 强制不按点分割   |

## 自定义 format

```ts
const i18n = new I18n({
  types: {
    default: {
      resources: { 'zh-CN': { hello: '你好 {{name}}' } },
      format: (str, options) => I18n.template(str, options),
    },
  },
})

// 或按语言指定
format: {
  'zh-CN': (str, options) => `【${I18n.template(str, options)}】`,
  'en-US': (str, options) => `[${I18n.template(str, options)}]`,
}
```

## applyConfig

动态追加或修改配置，第二参数为 `DeepMergeOptions`：

```ts
await i18n.applyConfig({
  types: { custom: { resources: { 'en-US': { world: 'World' } } } },
})

await i18n.applyConfig(newConfig, { mode: 'supplement' })

await i18n.applyConfig(newConfig, {
  mode: 'supplement',
  paths: { 'types.default.resources': 'override' },
})
```

### defaultApplyMode

通过 `I18nConfig.defaultApplyMode` 配置默认合并模式：

```ts
const i18n = new I18n({
  types: { default: { resources: { 'zh-CN': { hello: '你好' } } } },
  defaultApplyMode: 'supplement',
})

// 自动使用补充模式，不覆盖已有值
await i18n.applyConfig({
  types: {
    default: { resources: { 'zh-CN': { hello: '您好', world: '世界' } } },
  },
})
// hello → '你好'（保持），world → '世界'（补充）

// 显式 mode 始终优先于 defaultApplyMode
await i18n.applyConfig(config, { mode: 'override' })
```

详细的 `DeepMergeOptions` 说明见 [merge.md](merge.md)。

## fallback 翻译链

```ts
const fallbackI18n = new I18n({
  types: { default: { resources: { 'zh-CN': { shared: '共享' } } } },
})

const i18n = new I18n({
  types: { default: { resources: { 'zh-CN': { hello: '你好' } } } },
  fallback: [fallbackI18n],
  // 或 fallback: { common: fallbackI18n },
})

// 翻译优先级：主资源 > fallback 实例 > translateFallback > key 本身
```

## resources 格式

支持对象、函数、异步函数三种形式：

```ts
resources: {
  'zh-CN': { hello: '你好' },
  'en-US': () => ({ hello: 'Hello' }),
  'ja-JP': async () => { /* ... */ },
}
```

设置 `resources: false` 可禁用资源查找，配合 `format` 直接处理 key。

## priority 补充优先级

多包多层级注册语言包时，使用 `priority` 实现与注册顺序无关的优先级覆盖：

```ts
i18n.applyConfig(baseConfig, { mode: 'supplement', priority: 1 }) // 底层
i18n.applyConfig(midConfig, { mode: 'supplement', priority: 2 }) // 中间层
i18n.applyConfig(appConfig, { mode: 'supplement', priority: 4 }) // 应用层
```

规则：

- `当前 priority > 已有` → 覆盖
- `当前 priority = 已有` → 不覆盖（先到先得）
- `当前 priority < 已有` → 跳过
- 未指定 priority → 传统 supplement 行为

## 注意事项

- **I18n 是单例模式**：`I18n.applyLanguage()` 全局切换所有实例语言
- `applyConfig` 内部使用 `merge`，支持 `DeepMergeOptions` 所有选项
- `splitByDot: 'auto'` 优先按点分割查找，找不到再整体查找

## 相关函数

- `merge` — I18n.applyConfig 内部使用的高级合并函数
- `deepMerge` — 简单深度合并
- `I18n.template` — 独立使用的字符串模板函数
