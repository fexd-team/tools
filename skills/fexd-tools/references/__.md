# \_\_

柯里化占位符，用于偏应用（partial application）预填参数。

```ts
import { __ } from '@fexd/tools'
```

## 适用场景

- 配合 curry 做偏应用占位
- 跳过某些参数位置

## 不适用场景

- 不使用 curry 时无效
- 需要管道组合 → 用 pipe

## 签名

```ts
const __ =
  <T extends (...args: any[]) => any>(func: T, context?: any) =>
  (...preArgs: any[]) =>
  (...args: any[]) =>
    ReturnType<T>
```

## 用法

```ts
import { __ } from '@fexd/tools'

const greet = (a: string, b: string, c: string) => `${a} ${b} ${c}`
const sayHi = __(greet)('Hi', __, '!')

sayHi('World') // 'Hi World !'

// url 模块中的偏应用
import { param } from '@fexd/tools/url'
const getParam = __(param)(__, location.search)
getParam('id')
```

## 注意事项

- `__` 既是占位符常量，也是偏应用高阶函数
- 调用时按序用实参替换 `__`，剩余参数接在后面
- 可传 `context` 作为 `func.apply` 的 `this`

## 相关函数

- `curry` — 函数柯里化
- `pipe` — 函数管道组合
