# I18n

国际化工具类，支持多语言翻译、格式化模板、命名空间、资源加载和回退链。

## 类型签名

```ts
import { I18n } from '@fexd/tools'
```

## 交互演示

```jsx
import React, { useState, useRef, useCallback, useEffect } from 'react'
import { I18n } from '@fexd/tools'

const LANGS = ['zh-CN', 'en-US', 'ja-JP']
const FLAG = { 'zh-CN': '🇨🇳', 'en-US': '🇺🇸', 'ja-JP': '🇯🇵' }
const LANG_NAME = { 'zh-CN': '中文', 'en-US': 'English', 'ja-JP': '日本語' }

export default () => {
  const i18nRef = useRef(null)
  const [lang, setLang] = useState('zh-CN')
  const [name, setName] = useState('World')
  const [result, setResult] = useState({})

  useEffect(() => {
    const i18n = new I18n({
      types: {
        default: {
          resources: {
            'zh-CN': {
              hello: '你好',
              greeting: '你好，{{name}}！',
              nav: { home: '首页', about: '关于', settings: '设置' },
              weather: '今天天气 {{status}}',
              count: '共 {{n}} 条消息',
            },
            'en-US': {
              hello: 'Hello',
              greeting: 'Hello, {{name}}!',
              nav: { home: 'Home', about: 'About', settings: 'Settings' },
              weather: 'Weather is {{status}} today',
              count: '{{n}} messages',
            },
            'ja-JP': {
              hello: 'こんにちは',
              greeting: 'こんにちは、{{name}}！',
              nav: { home: 'ホーム', about: '概要', settings: '設定' },
              weather: '今日の天気は{{status}}です',
              count: '{{n}}件のメッセージ',
            },
          },
          format: (str, options) => I18n.template(str, options),
        },
      },
      splitByDot: true,
    })
    i18nRef.current = i18n
    I18n.applyLanguage(lang).then(() => refresh())
  }, [])

  const refresh = useCallback(() => {
    const i18n = i18nRef.current
    if (!i18n) return
    setResult({
      hello: i18n.t('hello'),
      greeting: i18n.t('greeting', { name }),
      home: i18n.t('nav.home'),
      about: i18n.t('nav.about'),
      settings: i18n.t('nav.settings'),
      weather: i18n.t('weather', { status: '☀️' }),
      count: i18n.t('count', { n: 5 }),
    })
  }, [name])

  const switchLang = async (lng) => {
    setLang(lng)
    await I18n.applyLanguage(lng)
    refresh()
  }

  useEffect(() => {
    refresh()
  }, [name, refresh])

  return (
    <div>
      <div style={{ display: 'flex', gap: 8, marginBottom: 16 }}>
        {LANGS.map((lng) => (
          <button
            key={lng}
            onClick={() => switchLang(lng)}
            style={{
              padding: '6px 16px',
              borderRadius: 8,
              cursor: 'pointer',
              fontSize: 14,
              border: `2px solid ${lng === lang ? '#1890ff' : '#e8e8e8'}`,
              background: lng === lang ? '#e6f7ff' : '#fff',
              color: lng === lang ? '#1890ff' : '#666',
              transition: 'all 0.2s',
            }}
          >
            {FLAG[lng]} {LANG_NAME[lng]}
          </button>
        ))}
      </div>

      <div
        style={{
          display: 'flex',
          gap: 8,
          alignItems: 'center',
          marginBottom: 16,
        }}
      >
        <span style={{ fontSize: 13, color: '#999' }}>name 参数</span>
        <input
          value={name}
          onChange={(e) => setName(e.target.value)}
          style={{
            padding: '4px 10px',
            borderRadius: 6,
            border: '1px solid #d9d9d9',
            fontSize: 14,
            width: 120,
          }}
        />
      </div>

      <div
        style={{
          borderRadius: 10,
          border: '1px solid #e8e8e8',
          overflow: 'hidden',
          background: '#fff',
        }}
      >
        <div
          style={{
            padding: '10px 16px',
            background: '#fafafa',
            borderBottom: '1px solid #f0f0f0',
            display: 'flex',
            gap: 24,
          }}
        >
          {['home', 'about', 'settings'].map((k) => (
            <span key={k} style={{ fontSize: 14, fontWeight: 500 }}>
              {result[k]}
            </span>
          ))}
        </div>
        <div style={{ padding: 20 }}>
          <div style={{ fontSize: 24, fontWeight: 700, marginBottom: 8 }}>
            {result.hello} 👋
          </div>
          <div style={{ fontSize: 16, color: '#333', marginBottom: 12 }}>
            {result.greeting}
          </div>
          <div
            style={{ display: 'flex', gap: 12, fontSize: 14, color: '#666' }}
          >
            <span>{result.weather}</span>
            <span>·</span>
            <span>{result.count}</span>
          </div>
        </div>
      </div>

      <div
        style={{
          marginTop: 12,
          padding: '8px 12px',
          borderRadius: 6,
          background: '#f6f6f6',
          fontSize: 12,
          fontFamily: 'monospace',
          color: '#666',
        }}
      >
        t('greeting', {'{'} name: '{name}' {'}'}) →{' '}
        <strong style={{ color: '#1890ff' }}>{result.greeting}</strong>
      </div>
    </div>
  )
}
```

## 实例配置

```ts
interface I18nConfig {
  types?: Record<
    string,
    {
      resources?: Record<any, any> | false // 翻译资源，false 表示不使用
      format?: any // 自定义格式化函数或按语言映射
    }
  >
  splitByDot?: boolean | 'auto' // 点分割模式：'auto'(默认)、true、false
  defaultType?: string // 默认类型，默认 'default'
  fallback?: I18n[] | Record<any, any> // 翻译回退
  translateFallback?: ((keys: any, options: any) => any) | any // 翻译回退函数
  defaultApplyMode?: 'override' | 'supplement' // applyConfig 的默认合并模式
}
```

## 构造参数

| 参数     | 类型         | 必填 | 默认值 | 说明           |
| -------- | ------------ | ---- | ------ | -------------- |
| `config` | `I18nConfig` | 是   | —      | 国际化配置对象 |

## 实例方法

| 方法                            | 说明                                                  |
| ------------------------------- | ----------------------------------------------------- |
| `t(key, options?)`              | 翻译 key，支持模板插值                                |
| `translate(key, options?)`      | `t` 的完整别名                                        |
| `applyConfig(config, options?)` | 动态追加配置，第二参数为 `DeepMergeOptions`           |
| `applyLanguage(lang)`           | 实例级切换语言（一般用静态方法 `I18n.applyLanguage`） |

## 静态方法

| 方法                                 | 说明                                                                                                                                                                                                                                                                             |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `I18n.applyLanguage(lang)`           | 全局切换语言，更新所有实例                                                                                                                                                                                                                                                       |
| `I18n.applyLng(lang)`                | `applyLanguage` 的别名                                                                                                                                                                                                                                                           |
| `I18n.template(str, data, options?)` | 字符串模板：`I18n.template('hello {{name}}', { name: 'CJY' })` → `'hello CJY'`。第三参数 `options?: { split?: boolean, fallback?: string \| ((key, orig) => string) }`：`split` 为 `true` 时返回分割后的数组；`fallback` 为变量缺失时的占位，默认 `'(unknow)'`，可为字符串或函数 |
| `I18n.load(...loaders)`              | 创建异步资源加载器                                                                                                                                                                                                                                                               |

## 翻译语法

| 语法               | 示例                                       | 说明             |
| ------------------ | ------------------------------------------ | ---------------- |
| 简单 key           | `t('hello')`                               | 直接翻译         |
| `@type`            | `t('key@error')`                           | 指定类型         |
| `namespace:key`    | `t('common:shared')`                       | 指定命名空间     |
| `@namespace` 选项  | `t('shared', { '@namespace': 'common' })`  | 选项指定命名空间 |
| `@splitByDot` 选项 | `t('user.name', { '@splitByDot': false })` | 强制不按点分割   |

### 命名空间用法

命名空间通过 `fallback` 的对象形式绑定，将翻译查找委托给其他 I18n 实例。指定命名空间有两种方式：`namespace:key` 语法，或 `{ '@namespace': 'xxx' }` 选项。

```ts
// 1. 创建公共模块的 I18n 实例
const commonI18n = new I18n({
  types: {
    default: {
      resources: {
        'zh-CN': { button: '按钮', link: '链接' },
        'en-US': { button: 'Button', link: 'Link' },
      },
    },
  },
})

// 2. 创建应用实例，将 common 注册为命名空间 fallback
const appI18n = new I18n({
  types: {
    default: {
      resources: {
        'zh-CN': { title: '标题' },
        'en-US': { title: 'Title' },
      },
    },
  },
  fallback: {
    common: commonI18n, // 命名空间名 -> fallback 实例
  },
})

await I18n.applyLanguage('zh-CN')

// 3. 本地资源
appI18n.t('title') // => '标题'

// 4. 通过 namespace:key 查找 fallback
appI18n.t('common:button') // => '按钮'
appI18n.t('common:link') // => '链接'

// 5. 等价写法：@namespace 选项
appI18n.t('button', { '@namespace': 'common' }) // => '按钮'
```

## 基本用法

```ts
import { I18n } from '@fexd/tools'

const i18n = new I18n({
  types: {
    default: {
      resources: {
        'zh-CN': { hello: '你好', 'greeting.morning': '早上好' },
        'en-US': { hello: 'Hello', 'greeting.morning': 'Good morning' },
      },
    },
  },
  defaultType: 'default',
  splitByDot: 'auto',
})

await I18n.applyLanguage('zh-CN')

i18n.t('hello') // => '你好'
i18n.t('greeting.morning') // => '早上好'
```

## 自定义 format

```ts
const i18n = new I18n({
  types: {
    default: {
      resources: { 'zh-CN': { hello: '你好 {{name}}' } },
      // 单个函数
      format: (str, options) => I18n.template(str, options),
    },
  },
})

// 或按语言指定
const i18n2 = new I18n({
  types: {
    default: {
      resources: { 'zh-CN': { hello: '你好 {{name}}' } },
      format: {
        'zh-CN': (str, options) => `【${I18n.template(str, options)}】`,
        'en-US': (str, options) => `[${I18n.template(str, options)}]`,
      },
    },
  },
})
```

## applyConfig 动态合并配置

```ts
// 默认 override 模式追加
await i18n.applyConfig({
  types: { custom: { resources: { 'en-US': { world: 'World' } } } },
})

// supplement 模式：不覆盖已有翻译
await i18n.applyConfig(newConfig, { mode: 'supplement' })

// 混合模式：全局 supplement，resources 路径依然 override
await i18n.applyConfig(newConfig, {
  mode: 'supplement',
  paths: { 'types.default.resources': 'override' },
})
```

### defaultApplyMode 默认合并模式

通过 `defaultApplyMode` 配置 `applyConfig` 的默认合并模式，省去每次调用时显式传入 `mode` 的麻烦。

```ts
// 创建时配置默认使用补充模式
const i18n = new I18n({
  types: {
    default: { resources: { 'zh-CN': { hello: '你好' } } },
  },
  defaultApplyMode: 'supplement',
})

// 之后 applyConfig 无需每次传 mode，自动使用补充模式
await i18n.applyConfig({
  types: {
    default: { resources: { 'zh-CN': { hello: '您好', world: '世界' } } },
  },
})
// hello 保持 '你好'（不覆盖），world 补充为 '世界'

// 仍可显式覆盖默认行为
await i18n.applyConfig(overrideConfig, { mode: 'override' })
```

| `defaultApplyMode` | 行为                                 |
| ------------------ | ------------------------------------ |
| 不设置（默认）     | `applyConfig` 默认 `override` 模式   |
| `'supplement'`     | `applyConfig` 默认 `supplement` 模式 |
| `'override'`       | 与不设置等效                         |

调用 `applyConfig` 时显式传入的 `mode` 始终优先于 `defaultApplyMode`。

## fallback 翻译链

```ts
const fallbackI18n = new I18n({
  types: { default: { resources: { 'zh-CN': { shared: '共享' } } } },
})

const i18n = new I18n({
  types: { default: { resources: { 'zh-CN': { hello: '你好' } } } },
  fallback: [fallbackI18n], // 数组：按顺序查找
  // 或 fallback: { common: fallbackI18n },  // 对象：命名空间
})

// 翻译优先级：主资源 > fallback 实例 > translateFallback > key 本身
```

## resources 格式

支持对象、函数、异步函数三种形式：

```ts
resources: {
  'zh-CN': { hello: '你好' },              // 对象
  'en-US': () => ({ hello: 'Hello' }),      // 函数
  'ja-JP': async () => { /* ... */ },        // 异步函数
}
```

设置 `resources: false` 可禁用资源查找，配合 `format` 直接处理 key。

## applyConfig 补充优先级 (priority)

多包/多层级注册语言包时，可通过 `priority` 实现**与注册顺序无关的优先级覆盖**。

### 场景

当多个包（底层组件库、中间框架层、上层应用）各自注册语言包时，期望上层翻译优先展示，但各包加载顺序不可控。

### 用法

```ts
// 每层注册时声明 priority，数值越大越优先
i18n.applyConfig(baseConfig, { mode: 'supplement', priority: 1 }) // 底层
i18n.applyConfig(midConfig, { mode: 'supplement', priority: 2 }) // 中间层
i18n.applyConfig(appConfig, { mode: 'supplement', priority: 4 }) // 应用层
```

### 行为规则

| 情况                          | 行为                                 |
| ----------------------------- | ------------------------------------ |
| 当前 priority > 已有 priority | **覆盖**（无论 target 是否已有值）   |
| 当前 priority = 已有 priority | **不覆盖**（先到先得）               |
| 当前 priority < 已有 priority | **跳过**                             |
| 未指定 priority               | 传统 supplement 行为（不覆盖已有值） |

### 注册顺序无关

```ts
// 以下两种顺序最终结果相同：
i18n.applyConfig(baseConfig, { mode: 'supplement', priority: 1 })
i18n.applyConfig(appConfig, { mode: 'supplement', priority: 4 })

// 反过来注册
i18n.applyConfig(appConfig, { mode: 'supplement', priority: 4 })
i18n.applyConfig(baseConfig, { mode: 'supplement', priority: 1 })
// 结果相同：appConfig 的翻译优先
```

### 性能参考

| 模式            | 四层注册耗时 (~7400 keys × 10 locales) |
| --------------- | :------------------------------------: |
| 传统 supplement |                 ~1.5ms                 |
| priority 模式   |                 ~26ms                  |

开销来源：需为每个 key 存储和比较优先级。仍在启动预算内（仅执行一次）。

### 与 shallowAfterDepth 组合

```ts
i18n.applyConfig(config, {
  mode: 'supplement',
  priority: 3,
  shallowAfterDepth: 4,
})
```

注意：`priority` 模式下 `shallowAfterDepth` 不生效（priority 使用独立的合并路径）。

## 注意

- `I18n` 支持多实例，每个实例可独立配置不同的 `types` 和 `resources`。`I18n.applyLanguage()` 会全局切换所有实例的语言。
- `applyConfig` 的第二参数为 `ApplyConfigOptions`（扩展自 `DeepMergeOptions`，增加 `priority` 字段），详见 [merge](../data/merge)。显式传入的 `mode` 会覆盖 `defaultApplyMode`。
- `splitByDot: 'auto'` 模式下优先按点分割查找，找不到时将点号作为完整 key 查找。
- `priority` 的优先级记录是**实例级别**的，不同 I18n 实例之间互不影响。
