# SAS

> ⚠️ 已废弃，请使用 [`singleflight`](../browser/singleflight) 代替。

```ts
import { SAS } from '@fexd/tools'
// 等价于
import { singleflight } from '@fexd/tools'
```

`SAS`（Single Advisory Service）是 `singleflight` 的旧名别名，功能完全一致。详见 [singleflight](../browser/singleflight)。
