# CombJudge

> ⚠️ 已废弃，请使用 [`CombinationMatcher`](../data/CombinationMatcher) 代替。

```ts
import { CombJudge } from '@fexd/tools'
// 等价于
import { CombinationMatcher } from '@fexd/tools'
```

`CombJudge` 是 `CombinationMatcher` 的旧名别名，功能完全一致。详见 [CombinationMatcher](../data/CombinationMatcher)。
