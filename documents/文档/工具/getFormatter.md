# getFormatter

> ⚠️ 已废弃，请使用 [`createSeparatorFormatter`](./createSeparatorFormatter) 代替。

```ts
import { getFormatter } from '@fexd/tools'
// 等价于
import { createSeparatorFormatter } from '@fexd/tools'
```

`getFormatter` 是 `createSeparatorFormatter` 的旧名别名，功能完全一致。详见 [createSeparatorFormatter](./createSeparatorFormatter)。
