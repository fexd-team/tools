# __ (下划线)

偏应用函数，支持占位符。使用 `__` 标记的参数位置将在后续调用时填充。

## 类型签名

```ts
const __ = <T extends AnyFunction>(func: T, context?: any) =>
  (...preArgs: any[]) => (...args: any[]): ReturnType<T>
```

## 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `func` | `T` | 是 | — | 要偏应用的函数 |
| `context` | `any` | 否 | — | 函数执行的 `this` 上下文 |

## 返回值

高阶函数 — 先传入部分参数（可用 `__` 占位），再传入剩余参数，最终返回原函数的结果。

## 示例

```ts
import { __ } from '@fexd/tools'

const greet = (name, greeting, punctuation) =>
  `${greeting}, ${name}${punctuation}`

// __ 作为占位符
const helloName = __(greet)('Hello', __, '!')
helloName('World')   // => 'Hello, World!'
helloName('Alice')   // => 'Hello, Alice!'

// 多个占位符
const addEm = __(greet)(__, 'Hi', __)
addEm('Bob', '.')    // => 'Hi, Bob.'
addEm('Eve', '!')   // => 'Hi, Eve!'
```

## 注意

- `__` 本身既是偏应用函数又是占位符标记，通过引用相等性（`preArg === __`）判断占位。
- 第一次调用传入的 `__` 占位数量必须等于第二次调用传入的参数数量。
